# Bhavika Vyas — Portfolio
A light minimalist portfolio with pastel vector illustrations. Built with Next.js (JavaScript), Tailwind CSS v4, Motion and Lucide React.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Resume download
Copy your final PDF into `public/Bhavika_Vyas_Resume.pdf`. The hero button already links to this filename.

## Add your photo later
In `app/page.js`, replace the dashed photo placeholder in the About section with an image stored in `public/`.

## Deploy
Push this project to GitHub and import it into Vercel. No environment variables are required.

Rekep and GitHub links are intentionally omitted per request.
